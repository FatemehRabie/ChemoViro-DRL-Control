# Optimal Control of Virotherapy-Chemotherapy via Deep Reinforcement Learning

This repository contains the source code, multi-seed experimental suite, Dynamic Programming (DP) grid ablation scripts, and statistical evaluation outputs for the paper:
**"Optimal Control of a Virotherapy-Chemotherapy Combination Model via Deep Reinforcement Learning: A Comprehensive Framework"** (*Computer Methods and Programs in Biomedicine*).

## Overview
This project benchmarks four continuous-action actor-critic Deep Reinforcement Learning (DRL) algorithms—**TRPO**, **PPO**, **TD3**, and **SAC**—against classical Dynamic Programming (DP) and matched open-loop dosing schedules on the nonlinear 4D (reduced, immune-excluded) and 6D (full, immune-active) chemo-virotherapy ordinary differential equation (ODE) models of Malinzi et al. (2017).

## Repository Contents
* `ODE-RL-Control.ipynb`: Interactive Jupyter Notebook containing the custom Gymnasium environment, Optuna hyperparameter search, agent training, and trajectory visualizations.
* `run_multiseed_drl.py`: Multi-seed training and evaluation suite (`5` independent seeds `[42, 123, 456, 789, 1024]` $\times$ `16` agent-scenario combinations = `80` trained models) evaluating cumulative reward, terminal tumor burden $(U+I)(T_f)$, cross-dimensional 4D$\to$6D transfer, the 6D zero-immune-lysis control ($\nu_U = \nu_I = \tau = 0$), and parametric uncertainty across 10 sampled ODE parameter sets.
* `dp_grid_ablation.py`: Vectorized 4D Dynamic Programming grid resolution sweep across $N_g \in \{10, 15, 20, 30, 50\}$ points per state dimension ($10^4$ to $50^4 = 6.25 \times 10^6$ states), measuring memory footprint, computation time, and policy return.
* `run_baselines_and_dp_ablation.py`: Grid search for matched open-loop constant and two-stage piecewise-constant dosing baselines under both high-toxicity-penalty ($A_1=10^{-2}, A_2=10^{-1}$) and low-toxicity-penalty ($A_1=10^{-7}, A_2=10^{-5}$) regimes.
* `statistical_summary.json` & `dp_ablation_results.json`: Complete multi-seed statistics (mean, SD, 95% confidence intervals, Mann-Whitney $U$ statistics, two-sided $p$-values, and rank-biserial effect sizes $r_{\text{rb}}$).
* `training_rewards_multiseed.png` & `dp_ablation.png`: Publication figures generated by the benchmark suite.

## Software Environment & Reproducibility
All experiments were executed with the following software stack:
* **Python:** `3.13.3`
* **PyTorch:** `2.7.1+cu128`
* **Stable-Baselines3:** `2.7.0`
* **SB3-Contrib (TRPO):** `2.7.0`
* **Gymnasium:** `1.2.2`
* **SciPy:** `1.16.1`
* **Optuna:** `4.5.0`
* **Random Seeds:** `[42, 123, 456, 789, 1024]`

### Running the Experiments
```bash
pip install torch gymnasium stable-baselines3 sb3-contrib scipy optuna matplotlib numpy

# 1. Run matched open-loop baseline grid search
python run_baselines_and_dp_ablation.py

# 2. Run 4D Dynamic Programming grid resolution ablation (10^4 to 50^4 states)
python dp_grid_ablation.py

# 3. Run 5-seed DRL training and statistical evaluation across Models 1-4 and Tests 1-4
python run_multiseed_drl.py
```
